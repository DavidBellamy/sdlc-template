# sdlc-template

A process-first template repository. The code is trivial on purpose; the value
is the software development lifecycle scaffolding around it.

## Start here

- **[The lifecycle](process/lifecycle.md)** is the process this template encodes,
  from stakeholders to launch. Read this first.
- **[RFCs and decision records](process/decision-records.md)** explains how
  proposals (issues) become decisions (ADRs).

## Working documents (in the repo, not this site)

- `plans/goals.md`: per-milestone goals, non-goals, definition of done.
- `plans/raci.md`: the Consulted/Informed that CODEOWNERS cannot express.
- `ROADMAP.md`: the narrative roadmap and out-of-scope list.
- `CHANGELOG.md`: the release and decision history.
